**Usage:** Paste this at the start of your Antigravity IDE session or FreeBuf terminal chat to give the AI full project context.

## Project Overview

Flicknest is a community-powered film discovery platform where users submit films and explain the deeper meaning behind each story. Cinematic UI with burgundy/gold/ember color scheme, glassmorphism cards, and framer-motion animations.

## Tech Stack

- **Framework:** Next.js 14 (App Router), TypeScript
- **Styling:** Tailwind CSS 3 with custom cinema theme variables
- **Animation:** Framer Motion 11 (scroll, layout, stagger, AnimatePresence)
- **Backend:** Supabase (Postgres, RPC, row-level security)
- **Forms:** react-hook-form + zod validation
- **Effects:** canvas-confetti, SVG film grain overlays
- **Fonts:** Bebas Neue (display), Lato (body)

## Key Architecture Decisions

1. **App Router:** All pages under `app/` with route groups, layouts
2. **CSS Variable Theme:** Colors in `globals.css` — `--cinema-black`, `--burgundy`, `--gold`, `--ember`, etc. Tailwind classes like `bg-cinema-card`, `text-gold`, `border-ember/50` throughout
3. **Client Components:** All pages are `"use client"` — no server components yet
4. **API Layer:** Supabase queries in `lib/api.ts` — `getMovies()`, `getMovieById()`, `incrementUpvote()`, `getGenres()`, `getWatchlist()`, `addToWatchlist()`, etc.
5. **Upvote Optimistic Updates:** UI increments immediately, reverts on failure
6. **Watchlist:** Anonymous user IDs via `lib/user-id.ts` (localStorage-based)
7. **Fallback Data:** `app/page.tsx` has `FALLBACK_MOVIES` array for offline/dev mode
8. **Movie Thumbnails:** 6 local thumbnails in `public/movie-thumbnails/` mapped to their movies via `/movie-thumbnails/*.png` paths — Midnight in Paradise, Velvet Thunder, Echoes of Tomorrow, The Parallax Effect, Embers of Empire, Where the Lotus Blooms. The other 11 movies use empty `poster_url` (triggers gradient fallback placeholder). All `<img>` tags have `onError` fallback handlers using the pattern: `useState(false)` for `imgError`, computed `showImage = !!movie.poster_url && !imgError`, and `onError={() => setImgError(true)}` on the img element. When an image fails, the existing gradient placeholder (title initial letter over burgundy/gold gradient) is shown instead. `decoding="async"` is used on all images for performance.
9. **OG Images:** Custom SVG fallback in `app/api/og/route.tsx`

## Components (in `components/`)

- `AnimatedBorder` — animated gradient border wrapper
- `CinemaCard` — modular card (poster/landscape/compact variants)
- `DiscoverCard` — card with upvote button for discover page
- `GlowBadge` — small pill badge (gold/burgundy/ember/gradient variants)
- `GradientButton` — CTA button (primary/secondary/ghost, sm/md/lg)
- `Sidebar` — persistent navigation sidebar
- `SpotlightHover` — spotlight cursor effect wrapper

## Pages & Routes

| Route | Description |
|-------|-------------|
| `/` | Hero with parallax, featured films carousel, all films grid, sticky genre filter |
| `/discover` | Full library with genre/sort/search filters, infinite scroll |
| `/movies/[id]` | Single film detail with hero, upvote, watchlist toggle, trailer embed, insight card, related films |
| `/submit` | Multi-section form with Zod validation, live preview panel, cinematic success overlay with confetti |
| `/watchlist` | User's saved films with remove capability |

## Conventions to Follow

- `font-display` for headings (Bebas Neue), `font-body` for text (Lato)
- `motion.div` with `initial/animate` or `whileInView` for all animations
- Glass panels: `glass-panel` class (backdrop-blur + semi-transparent bg)
- Cards: `bg-cinema-card border border-white/[0.06] rounded-2xl`
- Hover borders use "border-dance" animation style (CSS keyframe)
- Always handle loading/error/empty states for every view
- Optimistic updates for upvote/watchlist actions
- `AnimatePresence mode="popLayout"` for grid animations
